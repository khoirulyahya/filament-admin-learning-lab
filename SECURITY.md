# Security Policy

This repository is a **Filament learning lab**, not a production application.

## Reporting a vulnerability

If you find a security issue in this demo project, please open a GitHub issue with a high-level description (no exploit payload required), or email the maintainer listed in the README.

## Scope notes

- Demo credentials in the README are **synthetic** and intended for local use only.
- Do not deploy this project to the public internet without hardening authentication, authorization, and environment configuration.
- Never commit `.env`, API keys, private keys, or real user data.
